## Concrete divergences: preserve, do not normalize in place

| Surface | Evidence | Disposition |
|---|---|---|
| Enum keys | Master Schema _enum; Chronograf timescale_enum_str and Agent decision_enum_str | Both remain legal within their own version. New native Chronograf string enums follow its existing _enum_str pattern. |
| Object/array qualifiers | Time kernel uncertainty_group, barcode time_atom_obj, reference_chain_arr; topology loops_list and layers_map in channels | Preserve these names; the historical Master Schema gives patterns, not a formal distinct array algebra. |
| Unsuffixed Agent fields | action_intent and hyperaion_ref are objects in cognition-proposal schema | Preserve exact shapes and names. No cosmetic migrations. |
| CORE-D compact style | schema_version, record_id, evidence_refs, grants_authority, measured_at_ms and anchor_handle_uint64_dec | Independent candidate ABI uses a different naming profile. Bind it explicitly without renaming or treating aliases as interchangeable. |
| ID/reference patterns | Master Schema _id_str and _ref_str use restrictive lexical patterns; Agent anchor namespaces include URNs | Apply inherited patterns only within their defined scope. Domain-specific identifiers require explicit lexical profiles, not a global regex silently imposed. |
| Version syntax | Master Schema _semver_str pattern admits only MAJOR.MINOR.PATCH; VERSIONING.md explicitly permits prerelease tags | No global assumption of full SemVer from the historical regex. Specify intended version profile and request a versioned clarification from its owner. |
| Time syntax | Master Schema ISO8601 hint regex lacks fractional seconds; Chronograf represents subsecond ticks | No silent application of that regex to TimeAtom or a new timestamp profile. 0.3B defines the temporal lexical grammar. |
| Numeric semantics | Master Schema _int default and epoch_ms_int nonnegative hints; historical TimeAtom extended precision and signed epoch questions | 0.3B must define exact bounds, signs and transport. A generic type hint must not truncate or relabel time. |
| Canonical hashing | OpenRGD has its own source-tree hash profile | Reference it where applicable, but do not assume it canonically encodes TimeAtoms or signs temporal evidence. |

## Rules

No modification of OpenRGD Master Schema, its strict mirror, default seed, contracts, RGC-16 IDs, .rcg sources or historical manifests. Every field example above is evidence, not a migration mapping. A real rename, encoding change or semantic change requires a reviewed versioned contract delta, consumer impact report, test vectors, explicit loss/ambiguity handling and an adoption plan. Do not accept both spellings without a defined versioned adapter and conflict behavior. Preserve original evidence bytes and never change signed content under an alias. No runtime/schema conformance claims; this is a bounded documentation audit of the cited sources, not a complete inventory of every module.

OpenRGD owner handoff: retain its existing Master Schema as the shared convention root; if future work requires additional suffix semantics, lexical profiles or stricter validation, propose an additive owner-reviewed delta there. Do not create a duplicate master or require other modules to adopt this Chronograf-specific editorial profile.
